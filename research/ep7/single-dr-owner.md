# E-P7 1100 单帧 DR 冻结与传递接线

2026-11-07。原厂地址来自 decoded main `0x60020020`。本页区分已经接合的原厂指针和后续实现需要新增的所有权。已执行的阶段探针见 [曝光](single-dr-exposure.md)、[设置](single-dr-settings.md)和 [ISP](single-dr-tone.md)。

## 从捕获命令到传感器任务

1. 原厂 `6042760c` 准备 AE 输出，`60427733 → 603f38f8 → 603fbe7a` 求值，再由 `6042773f → 6042805e` 把同一输出结构的 `+8` 发布为 `A04A`。`6029cd4f → 602a7556` 领取 96 字节记录，在 `6029cd5c` 保存到当前命令 `+60`。`602ab5e4` 填写该记录，普通分支 `602ab693/6a6/6b9` 分别从原厂属性 `A02A/A04A/A03A` 读入 Tv/Sv/Av 至 `+6/+8/+10`。
2. 证据化的 mode 10 `STILL` 由 `602a6583` 经 `6029d3ca` 挂到 engine `+12`。`6029d3be` 初始化 engine `+4` 为 NULL。后来的 `6029d5d7/5da` 和 `6029f847/850` 分别从 `0x6223d414` 当前命令 `+60` 取实际记录，将其写入 engine `+4`，给出了原厂曝光记录与捕获命令的接合点。
3. `StlRdy2` 的第一条提交边 `6029d688–6029d695` 把 engine `0x6223d8a0` 交给 `601e77d8`。正常成功路径随后才在 `6029d7cd` 执行 `602a7ea0`，其中包含 015 的 H/L 采样。`StlLiveTake` 的 `6029f8fb–6029f925` 在传入同一个 engine 的同时取命令首字，`602aa5cc–602aa5ff` 将该值交给 `6029b85a/6029b986` 取得关联资源。实际 HDR 改动必须随该事务的身份传递，不能把 engine 的全局地址本身当逐帧身份。[状态与提交顺序](single-dr-settings.md#曝光提交与设置切换的交界)
4. 原厂低层 `601426b8` 有非空曝光对象复制，低层 `601428c8` 随后构造 type 0 计算命令，令命令 `+20` 指向工作曝光记录，`+4` 由模式描述符首字生产。`6012e69c–6012e6d3` 对求值 Sv 夹限并写 work `+46`，`6012e6d6–6012e6ec` 保留原始 Tv/Sv/Av 回显。`6012e6ef` 是实验上可修改求值 Sv 且保持原始回显的边界。严格探针验证该分离能到达 TG_GAIN 任务及串行载荷的低 8／高 4 位。
5. `601429ec/601429fd/60142a0e` 经外层原厂指针将三个回显半字写回。`602a91ee` 的当前命令 `+60` 随后被选帧事件处理读取，`602a92df/e2/e4` 将三项发布到捕获记录。这条边保留了既有曝光信息，新增的实际增益记录仍需独立传递。仅以名义 Sv 回显作为“已经降增益”的确认，会把 stock 成功或回退路径误报成 DR。

## 接线约束

- 固定 ISO 先闭合单张普通 STILL。设置作用域和拍摄资格须在提交曝光命令前绑定到当前捕获事务。实际模拟档位要按原厂合法模式和实装标定计算，确认调整后的结果达到要求时，才发布可供 ISP 消费的有效档位。若目标需要跨未知 TG 标志或超出已证实的模拟档位域，整个事务应按 OFF 继续。
- Auto ISO 还需要更早的边界，在原厂上限和默认值进入 AE 求解前施加约束，并使 AEL 与半按使用同一版本的设置。原厂 `ISO-Auto Set` 确有 `Upper Limit`、`Default` 两项。`60427984–604279af` 从 `949A/9A9A` 填入模式 `+24/+26`，同一布局由 `613ed407/418` 诊断为 `iso_limiter/iso_standard`。`603fcf22–603fcf2c` 的已查分支用 `EXP_SET+2` 区分求解与显式 Sv，非零时在 `603fcfe7` 写结果 `+8`。尚未把公开设置、各种曝光模式与捕获锁定版本接齐。[E-P7 原厂手册，p.147](https://download.omsystem.com/pages/inst/ep7/manual_ep7_ENU.pdf#page=147)
- 只冻结等级没有完成接线。需要让 JPEG 和取景消费同一策略的各自采集结果。曝光输出回显与真实 TG 参数已经分离，因而建议额外携带明确的 applied 状态以及 nominal/capture Sv，而不是从 `+48/+50/+52` 或当前 UI 倒推。对已进入 gain 路径的事务不能在 JPEG 回调晚回退为 OFF，否则中间调失配。启用前必须拥有两段传播能力及各自失败语义。
- 原厂选帧节点携带 capture ID，经 `602a281a → 602ac141/602ac1e1 → 602ac748` 的受限分支将其置于 kind19 metadata `+8`，`603f048b/0494` 从 ID 解出源 capture 指针。`603f283e` 构造 job，`603f2850` 调用转换器 `603e62d1`。现有 015 H/L 接线在 `602a886a`、`603e669f/603e91e4`、`603edbce` 分别处理采样、两条转 job 路径和 clone。015 已将原厂 job 的 15488 字节申请扩至 15512，初始化的 24 字节增量全部归 H/L。新状态应有自己的构造、拷贝和清除范围，或在可证明同一分配代、同一入队和释放周期的侧表里传递。现有 capture 地址、可重用 ID 和 gamma 实验的 `R+1884` 都没有这种所有权证明。[原厂 kind19 所有权](../../docs/ep7/KIND19_CAPTURE_ROUTE.md) · [015 H/L 传递](../../prototypes/ep7_volatile_hl/native_hsl/transport.c)
- `602a3204` 可能在 capture populate 前发布节点，释放后 registry `+12` 也可留旧指针。元数据池、capture pool、clone 和处理 job 各有自身生命周期。不能等后端发现缺档时再从当前设置补值；需要在发布前建立资格、随分配或请求身份传递并在释放前撤销。设置侧 bank 复制期间还可能读到过渡的 ACTIVE，单查一个原厂抑制标志不充分。[原厂 capture 分配和释放](../../docs/ep7/CAPTURE_ATTACHMENT.md) · [设置 bank 边界](single-dr-settings.md)

现阶段最重要的剩余证据是普通拍摄的 AE/AEL 与 bank 变化序列、早期采集所有权到后续 job 的不可变身份、独立取景增益及 ISP 请求的同义接线。标称 ISO 到实装模拟门槛、RAW 字段表示及高光的物理输出仍需单独验收。
