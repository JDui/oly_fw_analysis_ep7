# EP7HSL 024 / 1.1v024 SD 卡试用版

仅适用于 Olympus E-P7，基于原厂 1.1（build 1100）。024 增加 P/A/S/M 档的 Rec 一键 HDR1，使用当前单张驱动所选的快门。刷机和原厂回刷均依赖机身的 SD 更新入口。

## 刷入

1. 确认机型为 E-P7，备份 SD 卡照片和机身设置，使用充足电量的电池。刷前设为 **A 档、Natural（NAT）**。
2. 解压 ZIP，将 `install` 内的 `DCOLYMP` 文件夹放到 SD 卡根目录。确认路径为 `SD:/DCOLYMP/E1429999.BIN`。
3. 关机后插入更新卡。按住 **OK** 开机，AF 指示灯开始亮起后松开。等待灯由常亮转为快速闪烁，再关机。更新期间保持供电和插卡。
4. 关机后取出更新卡，正常开机。在版本页确认 BODY 显示 `1.1v024`，然后检查取景、菜单和普通拍摄。

回到原厂 1.1 时，将卡上的 `DCOLYMP` 替换成 `restore-stock` 内的版本，按同一流程操作。每次卡上只放一套更新文件。

## 验收 Rec HDR

1. 在 A 档打开 **按钮功能 → Rec（◎功能）→ HDR**。选择机械单张，对同一场景先按快门键拍一张，再短按一次 Rec，查看是否完成四帧曝光并保存一张合成照片。
2. 切到 **静音单张（♥）**，重复一次。检查 Rec HDR 是否使用电子快门，完成后再次按普通快门，确认仍是单张。
3. 正常关机后重开，确认 Rec 的 HDR 分配可读回。

Rec HDR 适用于 P/A/S/M 的单张驱动。离线验证覆盖快门选择、四帧计数、结束后单张计数和 SD 包加载路径。完整曝光、机内合成和相机端保存待实机验收。[024 实验接线与复现](https://github.com/JDui/oly_fw_analysis_ep7/blob/EP7/docs/ep7/REC_HDR_024.md)
