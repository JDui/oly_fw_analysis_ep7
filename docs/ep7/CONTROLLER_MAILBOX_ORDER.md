# Controller mailbox 顺序与 engine 分派

2026-10-31。本批关闭 mailbox1 的启动配置和正常 FIFO 数据路径疑问；不把
FIFO 误写成“回调恰好一次”或“邮箱永不重建”。候选代码没有安装或启用。

## 事件按值复制与 FIFO

`6020c0f0` 把 status/event/node 组成12字节记录，再调用 `6020c03c`。
后者查询 `60038521` 的 task/non-task 状态，从 pool1 取得 block，复制三个 word
到 block+8，然后分别调用 `60035db7` 或 `60031f1e` 投递 mailbox1。
临时发送栈不是入队对象；但记录中的 node 仍是裸指针，复制没有延长节点生命。

原厂 domain0 配置 root600411a4 的+144指向6003ad58，唯一启动行是
`{id=1, attributes=0, auxiliary=0}`；+220指向6003e89c，其首项为6219fb74。
`60032b6c` 把行的 ID 与两个配置 word 写入对象+0、+12、+16，
`60030c1b` 初始化 waiter 链和 message 链。message sentinel 位于对象+20。

两个 send API 都在 `60038594..6003860b` 内检查对象。attributes bit1 为0时，
没有等待者便把消息接到尾部；有等待者则直接写入其 TCB+96 并唤醒。
controller 使用的 `60033732` 是 poll receive，从 message 链头取出，空则返回-50。
`6020c101` 将 block+8的三个 word复制到调用方，再归还 pool1。
controller task60289852在602898ad接收，正常返回后按事件表执行6028992b间接调用。

因此，**在同一邮箱实例存活、发送成功且原厂临界区有效的条件下，controller
收到的消息保持入队顺序**。顺序由成功入队确定，不由两个回调开始运行的先后确定。
这不能排除并发产生两份0x4c，也不能保证0x4b已经成功投递。
发送失败走诊断并返回-1；只有成功分支到6020c0e8通知controller事件bit1。

non-task send 同样调用600314e6检查 handle 域。handle1没有0x8000跨域许可位，
其成功路径要求8050选择域0。这是API限制，不是所有engine回调实际都在域0的证明。

## 邮箱实例仍有生命周期

动态创建6003032f经6003521f扫描自动ID池1..31，空对象以 ID=0识别。
删除6003769a在临界区内唤醒等待者并于600377c7清ID；重建可以复用相同地址。
启动配置为FIFO不能排除后续配置不同的实例。

本次完整main的有限CALL字节扫描及精确目标核对得到：

|API|CALL位置|
|---|---|
|create6003032f|607796ee|
|delete6003769a|60779774|
|poll receive60033732|6020c10c|
|task send60035db7|6020c09d、6077994b|
|non-task send60031f1e|6020c0af、60779962|

没有找到这五个入口的绝对word引用。create包装器使用零属性并保存返回handle，
delete包装器从受管理对象+4取handle。**尚未证明该对象池只能持有动态创建的邮箱，
所以没有宣称mailbox1删除不可达。** 有限CALL扫描也不能排除计算地址或其他镜像入口。

## engine type7 不走通用回调分支

6029d351把engine6223d8a0的type设为7。601e77d8分派将type减4，
查表601ecc7c；key3的实际行601ecc94指向601e785a，进而调用6011f863。
不能把另一case使用的601e795c/6006857b通用回调队列套到本对象。

6011f863首先调用6006a922(2)。本批核对该包装器及60054d9f：后者按输入阈值
调整PSW的0x0700位，返回旧PSW；6006a96b负责恢复，并在相应条件下调用原厂
调度恢复入口。这些是当前二进制的具体行为，**不构成跨核全局锁或所有完成回调互斥
的证明**。engine提交中的保护区也不能自动延长到异步完成。

下一步应沿6011f863的实际图像处理完成回调和type39完成汇合审查域/优先级，
以及6077973a对象池的handle来源；不再沿不适用的通用callback case推导串行性。
