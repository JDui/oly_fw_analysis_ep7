# EP7HSL 023 / 1.1v023 高光过渡实验版

E-P7 原厂 1.1（build 1100），适用 COLOR 1–4。

022 实测拍完 HDR400 显示 `V42 P72`，JPEG 效果偏弱并有明显色阶。用户确认
HDR OFF 半按对焦时没有期望的变化，HDR200 和 HDR400 半按时则各有正确的效果。
022 的 V/P 码记录到 RGB 选表步骤，具体底表和实机 JPEG 的像素输出仍待确认。

## 曲线变更

在原厂 RGB Gamma 选表处直接换表。其后仍由原厂亮度曲线处理对比度及高光、
阴影和 Midtone。曝光和采集增益沿用原厂。

022 在原厂 Gamma 输出同为 3968（满量程 4095）的位置，三套 HDR400 表分别压
553、263、227 码，强度依底表而变。023 在这个亮度统一为 336 码，HDR200 为
168 码。亮度低于曲线起点时沿用原厂节点，肩部向白点逐步减小斜率，保留白端
4095。相机沿用原生缓存和上传路径。这些是 RGB 查找表数值，成片渐变和
半按效果是否接近仍需实机对照。

## 安装及一次对照

1. 将 `install/DCOLYMP` 放到 SD 卡根目录，按原更新流程安装，确认版本 `1.1v023`。
2. 在 COLOR1 用同一个有亮部渐变的画面，固定 ISO、快门、光圈和白平衡。保持
   原生曲线设置一致，分别拍 HDR OFF 和 HDR400 的新 JPEG。
3. 比较 400 半按时的高光和两张原始 JPEG，查看过渡是否接近、色阶是否减轻。
   拍完 400 后直接进 HDR 页读 V/P 码。

需要回到原厂 1.1 时，单独使用 `restore-stock/DCOLYMP/E1429999.BIN`。

## 023 选表码

V 是最近的取景观测，P 是最近的拍摄观测。第一位 `4` 表示普通 COLOR 请求键，
`7` 表示 COLOR 来源经验证、后续请求改用了其他内部键。两类都表示已选表。

| 原厂底表 | HDR200 | HDR400 |
| --- | --- | --- |
| 604ede78 | 41 / 71 | 42 / 72 |
| 604ee078 | 43 / 73 | 44 / 74 |
| 604f3e78 | 45 / 75 | 46 / 76 |

后续取景刷新可覆盖 V 的半按阶段记录。选表码描述 CPU 侧配置。其他状态码沿用
022 的定义。
