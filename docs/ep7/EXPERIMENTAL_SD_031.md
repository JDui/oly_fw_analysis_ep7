# EP7HSL 031 / 1.1v031 Rec HDR 试用版

适用于 Olympus E-P7 原厂 1.1（build 1100）。在 P/A/S/M 档沿用 **按钮功能 → Rec（◎功能）→ HDR**。按 Rec 使用镜头当前焦点，拍四帧并由原厂 HDR1 合成。普通快门半按对焦，全按拍单张。

直接按 Rec 时，相机走原厂测光和快门准备流程，跳过本次 HDR 的自动对焦请求。半按对焦完成时，继续半按并按 Rec，相机从原厂的拍摄准备完成状态进入 HDR。机械单张、防震单张和静音电子单张沿用各自的快门类型。

## 刷入和试拍

1. 刷前选择 **A 档、Natural（NAT）**。将 ZIP 内的 `install/DCOLYMP` 放到 SD 卡根目录。按原有流程刷入，开机后 BODY 初始版本为 `1.1v031`。[SD 卡刷入步骤](../../README.md#sd-卡刷入)
2. 选择 **S-AF、静音电子单张**。半按实体快门对焦，保持半按并按 Rec，观察四帧是否沿用锁定的焦点并自动合成。
3. 松开快门后直接按 Rec，观察镜头是否沿用当前焦点。再用实体快门确认半按对焦和全按单拍。
4. 回刷原厂 1.1 时，用 `restore-stock/DCOLYMP` 替换卡上的更新目录，按相同步骤刷入。

离线回放覆盖待机时的原厂测光分支、半按完成后的 Rec 调度、第四帧释放及静音 HDR 合成请求。镜头和传感器由回放夹具模拟，031 的镜头动作和成片待实机确认。
