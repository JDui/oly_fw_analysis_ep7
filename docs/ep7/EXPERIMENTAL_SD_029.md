# EP7HSL 029 / 1.1v029 Rec HDR 试用版

适用于 Olympus E-P7 原厂 1.1（build 1100）。在 P/A/S/M 档把 **按钮功能 → Rec（◎功能）** 设为 **HDR**。普通快门拍单张，按一次 Rec 启动四帧 HDR1 合成。Rec 使用当前的机械单张、防震单张或静音电子单张。

028 能启动对焦，但在离开待机时就撤销 HDR 参数，并且只提交了半按请求。029 沿用原厂立即拍摄流程的全按请求，保留 HDR 参数到拍摄结束或取消，再恢复单张。

## 刷入和试拍

1. 刷前选择 **A 档、Natural（NAT）**。将 ZIP 里的 `install/DCOLYMP` 放到 SD 卡根目录，路径为 `SD:/DCOLYMP/E1429999.BIN`。按原有 SD 更新流程刷入。[SD 卡刷入步骤](../../README.md#sd-卡刷入)
2. 正常开机后，按 Rec 前的 BODY 版本为 `1.1v029`。确认 **Rec → HDR** 已保存，并回到取景。
3. 用机械单张依次按 **普通快门 → Rec → 普通快门**。预期前后各保存一张普通照片，Rec 保存一张 HDR1 合成照片。再用静音单张（♥）重复一次，确认静音 HDR 后也能正常单拍。
4. 回刷原厂 1.1 时，用 `restore-stock/DCOLYMP` 替换卡上的更新目录，按相同步骤刷入。

## BODY 诊断

如果 Rec 停在对焦，先读 BODY，再半按快门解除。版本字母记录最近一次 Rec 的阶段，关机后清除。

| BODY 字母 | 阶段 |
| --- | --- |
| `v` | 开机后尚未识别 HDR Rec 按下 |
| `K` / `Q` / `D` | 已识别按下 / 已构造事件 / 拍摄任务已收到事件 |
| `S` / `L` / `W` | 拍摄任务忙 / 快门许可关闭 / 设置或触发占用 |
| `C` / `M` / `P` | 无法同步写入 / 模式或驱动条件不满足 / HDR 参数校验失败 |
| `T` | HDR 参数已准备，进入原厂待机判断 |
| `R` | 原厂待机判断已通过，全按请求已就绪 |
| `F` | HDR 临时参数已恢复，拍摄和取消均可走到此处 |

离线回放覆盖三种单张驱动下的原厂对焦完成回调、四帧 HDR 请求和回到待机时的属性恢复。镜头、缓冲区和传输服务使用夹具。实机曝光、合成和写卡仍待验收。
