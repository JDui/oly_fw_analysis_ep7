# EP7HSL 028 / 1.1v028 Rec HDR 试用版

仅适用于 Olympus E-P7 原厂 1.1（build 1100）。027 的实机反馈为 `1.1D027`，表明 Rec 事件已到拍摄任务。

原厂普通快门启用命令在 `0x60cd1e77` 将立即拍摄参数置零，经 `0x60cd209c` 传入释放服务。SDK 构造事件时将启用许可和立即拍摄参数分别写入，拍摄任务在 `0x60950aea` 保存为 `_activeRelease=1`、`_isTakePicture=0`。027 要求两者同时为 1。028 检查启用许可，并继续检查间隔拍摄、待机、设置和触发占用。

对照回放执行原厂释放状态写入函数，用普通启用参数复现 027 的 `D`。028 在相同输入下通过原厂待机判断，三种单张驱动选中各自的快门，结束后撤销 HDR1 的临时属性。媒体就绪及部分服务仍使用夹具。实际曝光、合成及写卡待实机验收。

## 刷入与回刷

1. 确认机型，备份照片及机身设置，使用充足电量的电池。刷前设为 **A 档、Natural（NAT）**。
2. 把 ZIP 中 `install/DCOLYMP` 复制到 SD 卡根目录，路径为 `SD:/DCOLYMP/E1429999.BIN`。
3. 关机插卡，按住 **OK** 开机。AF 指示灯开始亮起后松开 OK，等灯从常亮转为快速闪烁再关机。更新期间保持供电和插卡。
4. 取出更新卡后正常开机。尚未按过 Rec 时，BODY 显示 `1.1v028`。

回到原厂 1.1 时，换用 `restore-stock/DCOLYMP` 并按同一流程操作。每次卡上只放一套更新文件。回刷依赖机身更新入口。

## 实机验收

把 **按钮功能 → Rec（◎功能）** 设为 **HDR** 并退回取景。在 A 档选机械单张，依次试 **普通快门 → Rec → 普通快门**。预期前后各拍一张，Rec 保存一张 HDR1 合成照片。通过后切到 **静音单张（♥）** 重复一次。

如果 Rec 仍无响应，按一次后直接进固件版本页，记下 BODY 的完整文字。字母记录最近一次 Rec 的阶段，关机后清除。

| BODY 字母 | Rec 阶段 |
| --- | --- |
| `v` | 尚未识别到 Rec 的 HDR 按下事件 |
| `K` | 已识别按下，尚未构造拍摄事件 |
| `Q` | 已构造拍摄事件，尚未进入拍摄任务 |
| `D` | 已收到事件，尚未进入待机检查 |
| `S` | 拍摄任务当前不在待机状态 |
| `L` | 快门许可关闭或间隔拍摄会话占用 |
| `W` | 设置、触发或 HDR 请求占用 |
| `C` | 当前任务无法同步写入临时属性 |
| `M` | 模式、驱动或有效属性与单张 HDR 准入条件冲突 |
| `P` | 属性写入或 HDR 序列校验失败 |
| `T` | HDR1 已准备，开始调用原厂触发 |
| `F` | 原厂触发清理已恢复临时属性 |

成片以回放中能看到新照片为准。
