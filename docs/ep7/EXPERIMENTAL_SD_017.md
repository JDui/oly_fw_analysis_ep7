# EP7HSL 017 / 1.1v017

2026-11-08，E-P7 原厂 1.1 / build 1100 高光映射实验版。

本版修复 016 的 HDR 页面入口：去掉未经实机证实的 GUI 必须运行于 CPU 0 的限制，
复用原厂跨核设置队列，并保留页面与对象归属检查。设置暂时忙碌时仍能进入 HDR 页，
显示 Unavailable，拨轮不会误改 Midtone。相机版本页的机身版本显示为 **1.1v017**，
版本文字区域同步加宽。镜头／附件版本仍显示其实际版本。

016 在 CPU 1 回放中复现了“高光阴影 ↔ Midtone”的现象；017 在相同场景和 CPU 0
回归场景中完成三页循环与等级写入。尚未直接观测用户机身的 CPU 或完整运行状态，
因此这是有复现依据的修复，实机入口、版本显示与 JPEG 效果仍待试用确认。

## 安装与操作

1. 将 `install/DCOLYMP` 放在 SD 卡根目录，按此前使用的 E-P7 SD 更新方式安装。
   安装文件为 `install/DCOLYMP/E1429999.BIN`。
2. 在相机固件版本页核对机身显示 **1.1v017**。
3. 进入曲线页面，短按 INFO：**高光／阴影 → Midtone → HDR 等级 → 高光／阴影**。
4. HDR 页任一拨轮选择 **OFF / 200 / 400**。长按 OK 仅复位当前 HDR 等级。

恢复原厂使用 `restore-stock/DCOLYMP/E1429999.BIN`。卡上只保留要使用的那套 DCOLYMP，
不要合并安装与恢复文件。恢复包依赖相机更新入口可用。

本版保留 015 HSL 与 016 高光映射方向：ISO、曝光、AEL、采集增益保持原厂路径。
Natural / COLOR1–4、Normal Gradation 下使用两档高光压缩强度；200 / 400 不代表
测得的 EV 增益，也不会恢复采集或前级已经剪掉的细节。对比照片应保持曝光、ISO、
白平衡和构图一致。
