`EP7DR-NONINSTALLABLE.decoded-main.bin` 在同一个严格模拟器实例中运行了新增
owner、冻结／传递钩子、原生增益数值段和 gamma builder。固定名义 Sv=2048：
OFF 的两路控制字为 3583；200 为 3070；400 为 2046，数字乘数保持 65536。
A 在切换至 COLOR／400、复用原 capture 和 metadata 池位后，通过 clone 保留 200
的 LUT；B 使用 400；OFF 使用原厂 LUT。故意省略 selected-event 的绑定时，
capture 的 pending 状态传到 job，转换钩子返回 `0x9e02`，没有变成成功的 OFF。

该结果支持新状态传递的局部一致性，修复了上述“缺省 OFF 吞掉绑定丢失”的反例。
曝光桥接的 observer 实际为 64 字节，原对话指出的 60 字节偏移错误亦已修正并进入
此次候选。原生完整 RTOS 调度、property／allocator 响应、selected metadata body、
clone memcpy、converter body 由明确的服务夹具替代；job 几何与阶段来自显式输入。
因此不把此次通过写成完整相机拍摄回放或 ISP 像素验证。`0x9e02` 后的真实清理、
UI／持久化／取景及其他设计要求仍待接通和验收。原对话没有重复运行这些已通过的用例。
