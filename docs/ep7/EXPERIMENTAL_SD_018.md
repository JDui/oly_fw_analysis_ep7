# EP7HSL 018 / 1.1v018 — HDR 不可用定位版

2026-11-08，E-P7 原厂 1.1 / build 1100。

用户确认安装 017 后可以进入 HDR 页，但持续显示 `HDR Level: Unavailable`，
两个拨轮不能调整等级。**017 的等级选择实机验收失败，原因尚未定位。**

018 将统一不可用提示改为 `HDR unavailable: XXXX`，用只读方式显示阻断状态。
它保留 017 的读写守卫、高光映射、曝光／ISO 和 HSL 行为；不靠移除事务保护或伪造
OFF 值来使页面看似可用。机身版本显示同步为 **1.1v018**。

## 安装与反馈

将 `install/DCOLYMP` 放到 SD 卡根目录，按此前相同方式更新。进入 HDR 页后，
把 `HDR unavailable:` 后的四位字符反馈给本对话；若字符变化，请记录变化值。
本版的目的为取得机身实际阻断条件，不宣称已修复等级调节。

原厂恢复文件仍为 `restore-stock/DCOLYMP/E1429999.BIN`，安装与恢复两套目录不要
合并到 SD 卡。恢复依赖更新入口可用。

## 原因码

四位字符为十六进制位掩码，多个条件同时出现时合并显示。

| 位 | 实际读取条件 |
| --- | --- |
| 0001 | CPU 编号超出 0–2 |
| 0002 | 原厂加载标志缺失 |
| 0004 | ACTIVE 根指针为空 |
| 0008 | 原厂设置写入抑制 `62257b04` |
| 0010 | 原厂模式切换状态 `622484fa` |
| 0020 | HFW 冲突切换状态 `61fa7538` |
| 0040 / 0080 / 0100 | 本扩展记录的 core 0 / 1 / 2 bank 事务尚未退出 |
| 0200 | 原厂 typed queue 索引超出 0–15 |
| 0400 | typed queue 尚未清空或采样时发生变化 |
| 0800 | 设置作用域不支持 |
| 1000 | 当前曲线对象／公开模式对应关系未通过 |
| 2000 | 读取失败后，绘制提示时上述条件已恢复，需检查时序 |

显示仍取原厂 guide 文本通路；没有增加设备日志、图片读取、存储写入或等待循环。
离线定向回放验证各常见阻断码，并回归原有输入及映射；物理相机状态需要用户反馈。
