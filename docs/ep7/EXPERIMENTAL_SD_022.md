# EP7HSL 022 / 1.1v022 — COLOR 刷新与来源判定修正

2026-11-08，E-P7 原厂 1.1 / build 1100。支持 COLOR 1–4；曲线强度保持 021。

用户在 021 返回 `V42 P91`：正常预览和 JPEG 没有变化，但对焦过程中能看到认为
正确的 HDR 画面。此反馈优先指向刷新与处理路径切换，不再继续加重曲线。

## 本次修正

**补上取景刷新。** 021 的 HDR 拨轮只保存等级和重绘曲线菜单，没有调用既有
COLOR 调整使用的处理刷新入口。022 在接受改档或长 OK 复位后，复用 015 的
`ep7h_refresh` 及原厂对应 COLOR 回调。调用在设置写入／跨核入队之后、临界区之外；
INFO 切页、忙碌拒绝、拨轮已到边界时不触发。不会自动触发对焦。

**改正拍摄资格来源。** 021 要求后续每个 RGB 请求的内部键都严格等于 COLOR 11，
不符合就显示 P91。022 以该任务已经冻结的 COLOR1–4 来源及 HDR 等级判定资格，
允许该来源的普通兼容请求使用其他内部键。仍检查双向 owner 链、原生回调、类型
0/16、来源 1/2、内部特殊标志和三张已知相同 RGB 曲线。类型 3、未知表和不支持
条件继续原厂处理；不改写请求键或共享表。

非 COLOR 来源在采样及传递时写入 OFF，新任务构造也清零等级，因此不会因为它
后来使用 COLOR 请求键就启用 HDR。这里支持的是 COLOR 来源下的处理请求，不是
向 Natural 或 MONO 开放 HDR。

**避免部分过时状态。** 原 RGB selector 返回 0 时，旧桥接完全跳过观察器，屏幕
可能保留之前的 V42。022 对已绑定的有效 HDR 任务显示 C0，并保留原厂输出。
V/P 仍是最近观察记录，未经过观察器的其他路径不能据此判断，仍不是逐张完成凭据。

P91 没有记录实际的内部键值，也不说明被拒绝任务的完整像素去向。本版修复的是
可核实的代码缺口；不能宣称已完全复现此次相机从对焦到正常取景的调度过程。

## 安装与一次确认

1. 将 `install/DCOLYMP` 放到 SD 卡根目录，按此前方式更新，确认 `1.1v022`。
2. COLOR1 下先选 OFF，再选 400。退出曲线页，在曝光稳定时观察高光；半按对焦，
   再松开，确认效果是否能保持。无需设置“灰阶标准”，COLOR 没有这个菜单入口。
3. 用相同曝光和白平衡拍 OFF/400 的新 JPEG。400 拍完再进入 HDR 页读取 V/P，
   读取前不要转拨轮。反馈正常取景、松开半按后的表现及两组码即可。

原厂恢复文件在 `restore-stock/DCOLYMP/E1429999.BIN`。安装与恢复目录不要同时
合并到 SD 卡，恢复仍依赖可工作的更新入口。

## 状态码

| 状态 | 最近一次观察 |
| --- | --- |
| 00 | 切档清除后尚无记录 |
| 10 / 11 / 12 | 源快照为 OFF / 200 / 400，尚无后续记录 |
| 20 / 21 / 22 | job 收到 OFF / 200 / 400，尚无 RGB 记录 |
| 41 / 42 | COLOR 键请求选择了 HDR200 / HDR400 表 |
| 71 / 72 | 已验证 COLOR 来源、后续内部键不同的请求选择了 HDR200 / HDR400 表；不是错误 |
| C0 | selector 返回非普通成功状态，此次保留原厂映射 |
| 50 | 设置快照遇到忙碌或待处理队列 |
| 60 | 源 owner 或模式不属于支持的 COLOR 路径 |
| E0–EF / F0–FF | 不支持的请求类型／来源；低位为字段值，15 及以上饱和为 F |
| A0 / A1 | 内部 Gradation／特殊处理标志不兼容，由固件侧排查 |
| B0 / B1 | 三通道表不同／原表不在已支持列表 |
| D0 | 本任务冻结等级为 OFF 或无效 |

91 在本版不再使用。41/42/71/72 均只表示选表，不代表真实 ISP 或 JPEG 像素验收。
切档清除记录，重新进入页面读取；未增加持续刷新定时器。

## 本地检查范围

在同一候选上检查 COLOR 来源请求换键后的拍摄／预览映射、非 COLOR 清零、原厂
RGB selector 返回 0 时的输出等价、缓存、OFF、复用表和原上传函数对模拟表区的
写入。检查 CPU 0/1 的 INFO、双拨轮和长 OK：每次有效改档恰好触发一次原厂 COLOR
回调，边界／拒绝操作不触发，跨核操作先入队后回调。回调内部的属性数据库与有效
参数发布是模拟服务边界，没有执行完整实时调度，也没有模拟 AF 或真实图像像素。

设置、版本显示与最终交付封装沿用定向检查。最终镜像须等于已测候选，核对既有
加载器、两份 ELF 叠加、五组件加和、原厂升级路由拦截和 ZIP 回读。未做 SHA 或
相机写入。本版真实取景、JPEG 效果及关机保存仍待用户实机确认。
