## 产物与改动

通过的构建目录是 `generated/ep7/offline-candidate-005-r2/`，源版本 `8eedce7`。
`005` 和 `005-r1` 是保留的链接失败记录，不是有效候选：GNU 把 BSS 转为 PROGBITS
的警告触发了 `--fatal-warnings`。最终显式指定类型并先写一个零数据字，随后放入
BSS，严格链接无警告通过。106 个对象仅编译一次，两次重试复用全部对象。

通过。decoded main 26,214,336B，实际变化54,405B。没有新清零 hook 或池保留时点。
