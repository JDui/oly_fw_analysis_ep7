# EP7HSL 026 / 1.1v026 Rec HDR 试用版

**实机结果**　普通快门可正常单拍，Rec 仍无响应。后续对照发现 026 要求单张驱动的连拍属性已开启，且把自定义自拍的编号当成了静音单张。[027 修正版](EXPERIMENTAL_SD_027.md)

仅适用于 Olympus E-P7 原厂 1.1（build 1100）。025 实机已恢复普通单拍。Rec 分配为 HDR 后短按仍无反应。

原厂单次拍摄接收函数在 `0x60953b54` 检查间隔拍摄会话标志。正常单张待机时该位为零，025 会直接跳到回复路径。先前回放把该位置为已启动，漏掉了这项拒绝条件。026 将带 Rec 标记的请求接到普通拍摄的许可条件，使用原厂待机触发，间隔拍摄命令继续使用原厂会话检查。

对照回放从原厂事件 `1007` 分发开始，以间隔标志清零复现 025 的拒绝。026 到达原厂待机拍摄触发入口，电子 HDR 计数为四帧，触发清理后恢复为普通单帧。回放也检查了拍摄许可关闭、半按、重复请求和原厂间隔拍摄。

## 刷入与回刷

1. 确认机型、备份照片及机身设置，使用充足电量的电池。刷前设为 **A 档、Natural（NAT）**。
2. 把 ZIP 中 `install/DCOLYMP` 复制到 SD 卡根目录，路径为 `SD:/DCOLYMP/E1429999.BIN`。
3. 关机插卡，按住 **OK** 开机。AF 指示灯开始亮起后松开 OK，等灯从常亮转为快速闪烁再关机。更新期间保持供电和插卡。
4. 取出更新卡后正常开机，确认 BODY 显示 `1.1v026`。

回到原厂 1.1 时，换用 `restore-stock/DCOLYMP` 并按同一流程操作。每次卡上只放一套更新文件。回刷依赖机身更新入口。

## 实机验收

在 A 档选择机械单张，把 **按钮功能 → Rec（◎功能）** 设为 **HDR**，按 OK 保存并退回取景。依次试 **普通快门 → Rec → 普通快门**。前后都应是单张，Rec 应完成一组 HDR1 并保存合成照片。再选 **静音单张（♥）** 重复一次，确认 Rec HDR 沿用电子快门。

026 通过了离线触发回放和 SD 封装。机身任务调度、实际曝光、保存与合成待实机确认。
