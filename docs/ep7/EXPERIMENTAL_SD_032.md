# EP7HSL 032 / 1.1v032 Rec HDR 试用版

适用于 Olympus E-P7 原厂 1.1（build 1100）。在 P/A/S/M 档沿用 **按钮功能 → Rec（◎功能）→ HDR**。按 Rec 使用镜头当前焦点，并用所选的机械单张、防震单张或静音电子单张快门拍四帧，由原厂 HDR1 合成。普通快门半按对焦，全按单拍。

031 在 S-AF 下直接按 Rec 时，原厂对焦控制器仍会生成带 AF 的拍摄准备命令。032 在 Rec 持有拍摄请求时，从原厂对焦控制器的资格判断进入无 AF 的准备分支，同时保留原厂测光与四帧合成。

## 刷入和试拍

1. 刷前选择 **A 档、Natural（NAT）**。将 ZIP 内的 `install/DCOLYMP` 放到 SD 卡根目录。按原有流程刷入，开机后 BODY 初始版本为 `1.1v032`。[SD 卡刷入步骤](../../README.md#sd-卡刷入)
2. 选择 **S-AF** 和原来复现故障的快门类型，回到取景后直接按一次 Rec。观察镜头是否保持当前焦点，并检查相册是否出现 HDR 合成图。
3. 用实体快门半按对焦，保持半按再按 Rec，确认沿用已锁定的焦点。随后用普通快门拍一张确认单拍。
4. 回刷原厂 1.1 时，用 `restore-stock/DCOLYMP` 替换卡上的更新目录，按相同步骤刷入。

`1.1R032` 表示 Rec 已排入拍摄，`1.1N032` 表示对焦控制器已为本次 Rec 跳过 AF，`1.1U032` 表示第四帧已到，`1.1F032` 表示拍摄临时参数已恢复。

定向离线回放在相同的 S-AF 条件下观察到 031 的原厂准备命令要求 AF，032 的命令关闭 AF 且通过原厂释放许可。机身实际镜头动作、曝光与合成待实机确认。
