# EP7HSL 025 / 1.1v025 Rec HDR 修正版

仅适用于 Olympus E-P7 原厂 1.1（build 1100）。024 实机反馈按下 Rec 后普通快门和 Rec 都失效，MENU 仍可用。

024 在原厂 HDR 子界面关闭快门释放后转去发单次拍摄请求，随后直接返回。025 在子界面关闭释放之前分流 Rec，仍检查拍摄模式、忙碌状态和当前单张驱动。定向回放复现了 024 提交时及返回后的释放锁定，并确认 025 在同一入口只发出一个请求、快门释放保持可用。

## 刷入与回刷

1. 确认机型、备份卡上照片与机身设置，使用充足电量的电池。刷前设为 **A 档、Natural（NAT）**。
2. 把 ZIP 中 `install/DCOLYMP` 复制到 SD 卡根目录，路径为 `SD:/DCOLYMP/E1429999.BIN`。
3. 关机插卡，按住 **OK** 开机。AF 指示灯亮起后松开 OK，等灯从常亮转为快速闪烁再关机。更新期间保持供电和插卡。
4. 取出更新卡后正常开机，确认 BODY 显示 `1.1v025`。

回到原厂 1.1 时，换用 `restore-stock/DCOLYMP`，按同一流程操作。每次卡上只放一套更新文件。回刷依赖机身更新入口。

## 验收

1. 在 A 档和机械单张下，将 **按钮功能 → Rec（◎功能）** 设为 **HDR**，按 OK 保存并退回取景。菜单帮助沿用原厂的「切换 HDR 开/关」。
2. 先按快门拍一张，再短按一次 Rec。确认 HDR 曝光结束后再按快门，仍能拍摄单张。
3. 切到 **静音单张（♥）** 重复一次，确认 Rec 使用电子快门并保存 HDR 合成照片。

025 已做离线 Rec 回放、版本显示、加载与 SD 封装检查。实际开机、曝光和机内合成待实机验收。
