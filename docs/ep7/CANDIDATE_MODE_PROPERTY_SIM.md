原类型化writer在缓存地址和`+40000000`地址各有一次store。四份已由原生ROM/default

186493B。没有增加独立默认值或另一份NVM副本；真实CPU cache coherence仍未证明。

新增26933B是已审查初始化/写入范围的容量，含20×64B复合返回ring；这不表示所有
ring槽已经使用。新区域先填A5，原代码负责写值。另有3B明确冷态BSS条件：2个日志
开关和复合返回ring的selector。18B从已审查的原厂initialized-data搬运配方取值，
其中两个全局post-hook仍为初始NULL；并未声称执行NAND/cache启动搬运或后续hook注册。

资源reset仅执行52B计数前缀，其后队列清理和完整资源任务未执行。设备reset也只
执行列出的片段。公共setter完整返回是在这些明确冷态条件下完成，不能替代实机
模式切换、活动帧或异步消费者一致性验收。
