# EP7HSL 010：曲线页面故障的 AF 分组诊断版

2026-11-02。009 已由用户确认刷入、启动成功；切换到高光／阴影曲线页立即卡死并重启，
期间 AF 灯连续均匀闪烁，色轮只能调 S。**010 是诊断包，尚未修复曲线卡死或 H/L 不可用。**

## 本次修改

仅修改终止处理 `runtime/quarantine.s` 的 AF 提示选择，保留第一个完整终止码、
原有 CPU 域和加载状态检查、单次原厂 helper 调用以及停机保护。正常启动、页面、
按键和照片处理实现保持 009 的源码。使用原厂 `601e73e5` 已支持的模式，不增加
灯控循环、延时、闪存写入或日志文件。

| 卡死后的 AF 表现 | 原厂模式参数 | 对应终止码范围 |
| --- | --- | --- |
| 常亮 | 255 | 显示文字／控件所有权 `0x700–0x7ff` |
| 比 009 更快闪烁 | 100ms | 按键与事件处理 `0xc00–0xcff` |
| 最快闪烁，可能看起来接近常亮 | 50ms | 页面对象、内容、模型、绘制及入口保护 `0x800–0xbff`、`0xd00–0xdff` |
| 与 009 相同速度 | 250ms | 其他终止原因，包括运行时、拍摄和启动保护 |

以上是传给原厂 helper 的模式，不是已测得的机身闪烁周期。离线检查只能确认
调用参数和原厂 PWM 配置；实机亮灭、可见速度及复位原因仍未知。常亮与最快闪烁
可能不易肉眼区分，短视频可帮助判断。熄灭或模式不明也不能排除终止路径。
灯光仅区分四组，不直接提供完整错误号；不得据此绕过保护。

沿用 009 已成功的 SD 更新方法，每次只放一套 `DCOLYMP` 到卡根目录；保持充足电量，
不要在更新过程中断电。更新完成后关机并取出更新卡，再正常开机。

本次只需观察能否启动，以及重现一次“切换到曲线页”时 AF 灯与 009 相比是常亮、
更快、最快还是同速。最好保留从切换前至重启的短视频。出现同样卡死后不反复触发，
按此前成功的方法使用 `restore-stock` 恢复。原厂文件依赖仍可用的更新入口，
它不是独立救援镜像；本轮未操作相机或 SD 卡。

现有实现把 H 和 L 放在曲线之后的两个独立类别，原 S 色轮不会自动变成 H/L 切换。
曲线入口卡死可能阻断继续访问 H/L；这只是当前结构能解释的关系，尚非唯一根因证明。
