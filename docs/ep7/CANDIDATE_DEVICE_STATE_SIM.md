## 原厂初始化与转换

真实60020117..60020139执行3379条指令，将ROM6002e020..6002e8e8的562个word复制
到61b20fe0..61b218a8；2248字节与ROM逐字节一致。61b217cc的六行remap descriptor
随之生成：前五行pointer=61b217a4+i*8、count=0，第六行pointer/count均为0。
旧研究覆盖前五行；本节点也确认原厂对较大编号使用的第六行。

原厂600222a2读取ROM6002419c/600241a0/6002421c中的三个寄存器地址：
9b800b2c、9b800b4c、9b8010ec。先保存并配置各自+4控制word及9b800188，再读取
三个bit4组成3bit值，调用600226bb查询ROM60026ce0，写8ff00198，最后恢复控制word。
探针显式提供各输入bit、无关干扰bit和不同的控制word初值；这些值是离线输入，
不是相机测量。每次调用后，输入及控制region全部字节必须与调用前相同。

随后执行完整6011681d[f0],20：真实读取600226f7，查询601aa02c，写a272ba94并清除
a272bae8起每隔100字节的五个状态字节。再执行原厂60022090前缀，停在600220a9，
得到GPIO remap selector。完整211-port配置循环尚未执行。

## 两个真实输入停止点

第一条为60118093[f0],60的GPIO采样前缀，原厂调用点6011689b。本节点提供
621db590的18字节A5计数区、621db588的两个A5指针、两个A5 shadow字节；原生执行
清计数并填入ROM指针。a272bce8的两个OR累积字节明确以已定位第二BSS范围清零成功
为条件，未执行DMA，也没有扩展成整片未知BSS零填充。

当前182条指令后，logical port102经原厂60021ffe→60022056→60022254解析，
在60022085读取9b80108c的4字节时停止。6203c794由真实前缀初始化为5，第六行
remap count=0，因此原厂保留port102；ROM60024078+102*4确实指向9b80108c。
计数和指针已初始化，采样shadow仍为A5，不能将部分结果当作有效GPIO快照。

[此前的157指令停止点](../../research/ep7/candidate-device-selector-frontier.json)
停在60022257读取6203c794；其schema和当时实际寄存器独立保留。该缺口已由原厂
选择器前缀和CPU初始化数据复制关闭，当前不是直接填入一个零selector绕过。

第二条独立执行60118545→600668b4，在第2条指令读取98e00058时停止。该函数随后
还需98e0005c/60/64/68的bit31，组合为五bit snapshot，供601168ba的初始256查询
使用。本节点没有提供这些寄存器，a272bcec和621db5a4两个目的字节均保持A5。

两条fault均固定PC、地址、宽度、访问方向和未映射状态；诊断、quarantine或其他
fault不能算通过。本节点合计8590条新执行指令，最大新增观测调用深度104字节，
不是完整任务栈上界。

原几何构造栈和故障寄存器保留，partial capture全27332字节不变。601168ba完整重置、
有效设备快照、6042805e动态setter和capture population尚未接通。下一步可在明示
硬件输入的离线模型下验证采样/谓词分支及后续配置；实机引脚状态、外设时序、IRQ和
完整任务启动仍须单独证明。候选004仍不可安装，S3未整体完成，无重编译/SHA/真机操作。

## 复现

```sh
python3 /repo/tools/ep7_candidate_device_state_sim.py \
  --candidate /repo/generated/ep7/offline-candidate-004 \
  --tool-prefix /work/install/bin/mn10300-elf- \
  --engine /work/ep7-mn103-sim-87ffb882-complete/build/ep7-mn103-mulqu
```

预期board_publication_and_selection_passed=true，两种snapshot_passed均false；
geometry_resumed/population_resumed均false。命令成功退出不表示设备输入已经提供。
