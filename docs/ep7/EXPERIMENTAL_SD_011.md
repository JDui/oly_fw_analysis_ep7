## 操作

1. 进入原来的 COLOR 色轮页，按删除键循环 **S → L → H → S**。
   轴标题分别显示 Saturation、Lightness、Hue；当前色区位置保持不变，
   数字及色轮轮廓一起切换。H/L 不再放在曲线后的独立页面。
2. 原来的前拨轮选色区、后拨轮改数值、INFO 切 ALL 操作继续使用。
   四个 COLOR 组分别保存 H/L。E-P7 的原厂范围为 **−5～+5**，011 保留此范围；
   操作方式参照 PEN-F，未把 PEN-F 的 −7～+7 硬套进 E-P7 的 11 档图形表。
3. 每次调节通过原厂设置记录写入；短按 OK 沿用原厂退出行为，
   长按 OK 沿用当前轴的复位操作。H/L 复位值为 0，不改另一轴或原来的 S。
4. 重启后默认显示 S。再次切至 H/L 查看保存值；轴选择本身是会话状态。

## 修改方式

复用 `patches/hsl/pen-f/src/editor_storage/` 的同色轮切轴、H1 编码与原厂设置思路，
按 E-P7 的四组属性 ID、调用约定、子项布局与绘制接口重新绑定。
H/L 存在原厂 ACTIVE 的 part-1 单元，整组保存、召回、关机保存由原厂设置机制管理。
没有新增文件写入或私有闪存写入器。原 S 数据保持原路径。

撤下 009/010 的 22 个 GUI 扩展钩子及对应构建对象，恢复原厂四类 COLOR 页面、
曲线页和页面对象生命周期。保留已修正的启动及拍摄传输路径。
拍摄边界按该张照片捕获的 COLOR 组读取 H/L，再冻结进该照片的 sidecar，
由现有 CPU 调色处理使用，后续编辑不改变已经冻结的照片参数。
