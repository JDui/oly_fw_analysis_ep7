# EP7HSL 019 / 1.1v019 — 修正 HDR 等级持续不可用

2026-11-08，E-P7 原厂 1.1 / build 1100。

018 实机反馈为 `HDR unavailable: 0010`。已查明此前将原厂持续保留的模式会话
标志误当成了“正在忙”，导致进入 HDR 页后无法读取或切换等级。

019 改为保护模式处理函数实际进入到返回的区间；不修改、清零原厂会话标志。
INFO 三页切换和原有高光映射保留，机身版本显示同步为 **1.1v019**。

## 安装与操作

1. 将本包 `install/DCOLYMP` 放到 SD 卡根目录，按此前相同方式更新。
2. 机身版本页应显示 `1.1v019`。
3. 打开曲线，短按 INFO：高光／阴影 → Midtone → HDR 等级。
4. 正常应显示 `HDR [OFF] 200 400`。转动任一拨轮，方括号应随所选等级移动；
   到达端点后停止。长按 OK 将当前 HDR 等级复位为 OFF。

原厂恢复文件是 `restore-stock/DCOLYMP/E1429999.BIN`。安装和恢复两套目录不要
同时合并到 SD 卡；恢复仍依赖相机更新入口可用。

## 本版验证范围

- 实际执行原厂会话进入、再次进入、退出的控制流，确认进入返回后标志仍为 1；
  两个进入分支及内外嵌套事务观察均通过。属性通知与内层模式副作用是模拟边界。
- 持续保留该标志，CPU 0/1 的 INFO、双拨轮、长按复位、原生设置队列、重建和
  清理回放通过；真实忙碌条件仍显示原因码并拒绝不稳定设置。
- 同状态下，ACTIVE 读写、原厂 bank 保存召回、拍摄／预览等级快照、原生 gamma
  构建通过；原高光阴影数据保留。原厂曝光、ISO、采集增益路径保持不变。
- 两处机身版本显示通路验证为 `1.1v019`。最终安装镜像须与已测试镜像逐字节一致，
  经既有原厂加载、五组件封装、升级路由拦截和 ZIP 回读流程后才输出。

以上是软件回放与封装验证，尚未完成 019 实机拨轮、关机保存及 JPEG 效果验收。
200/400 表示高光映射强度，不代表经测量的动态范围倍数。

## 原因码变更

`0010` 已停用：`622484fa` 是会话状态，不是忙碌条件。其余原因码沿用 018；
实际事务由 `0040 / 0080 / 0100` 表示三个核的未结束操作，原厂写入抑制、HFW
冲突状态及 typed queue 守卫仍有效。若仍出现不可用，可反馈完整四位字符。
