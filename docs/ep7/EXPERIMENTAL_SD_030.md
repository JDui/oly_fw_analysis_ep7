# EP7HSL 030 / 1.1v030 Rec HDR 试用版

适用于 Olympus E-P7 原厂 1.1（build 1100）。在 P/A/S/M 档把 **按钮功能 → Rec（◎功能）** 设为 **HDR**。普通快门拍单张，按一次 Rec 发起四帧 HDR1 合成。Rec 沿用当前的机械单张、防震单张或静音电子单张。

029 在机械和防震单张上拍完四帧后要半按快门才能合成。回放显示原厂收尾会根据 029 保留的全按事件重新锁存快门状态。030 在原厂第四帧计数到限时解除模拟全按，用原厂函数重新读取实体快门，并保留本次 HDR 参数到收尾。静音单张沿用电子快门参数，交给与机械和防震相同的原厂 HDR 连续拍摄路径。

## 刷入和试拍

1. 刷前选择 **A 档、Natural（NAT）**。将 ZIP 内 `install/DCOLYMP` 放到 SD 卡根目录，路径为 `SD:/DCOLYMP/E1429999.BIN`。按原有 SD 更新流程刷入。[SD 卡刷入步骤](../../README.md#sd-卡刷入)
2. 正常开机后，按 Rec 前的 BODY 版本为 `1.1v030`。确认 **Rec → HDR** 已保存，并回到取景。
3. 在静音电子单张（♥）、JPEG＋ORF 下依次按 **普通快门 → Rec → 普通快门**。查看 Rec 是否自动完成四帧合成，相册是否出现合成 JPEG，以及两次普通快门是否各拍单张。再用机械单张试一次，确认拍完四帧后自动合成。
4. 回刷原厂 1.1 时，用 `restore-stock/DCOLYMP` 替换卡上的更新目录，按相同步骤刷入。

## BODY 诊断

| BODY | 阶段 |
| --- | --- |
| `1.1v030` | 开机后尚未识别 HDR Rec 按下 |
| `1.1R030` | 全按请求已就绪 |
| `1.1U030` | 原厂已数到第四帧并接手收尾 |
| `1.1F030` | HDR 临时参数已恢复 |

离线回放覆盖三种快门的第四帧释放和收尾判断，以及静音电子单张的四个曝光句柄进入原厂合成请求。用户确认 030 的 Rec HDR 在实机上奏效，并提出让 Rec 沿用已有焦点。[031 试用说明](EXPERIMENTAL_SD_031.md)
