## Important counterexamples / exclusions

1. Same node queue has another producer6029ce67 requesting56 atce69; ce83 associates record andce8f enqueues. Merely expanding3116 does NOT authorize reading an extension on every node taken from the queue. Require live expanded-allocation membership BEFORE trailer reads, or explicitly expand/neutralize every supported alternate producer with separate review. A tag read is not itself allocation-size proof.
2. 3116 itself also has caller6029cdd0; that path sets associated+6=1 and enqueues atce11 without the31ea/31f7 population envelope. Those allocations must remain UNSEALED/neutral unless independently qualified.
3. c748 has another direct caller602ac60e. Its associatedrecord is popped from queue6223e7dc into d2 (c5ef), not a2; getterc609 yields captureID. An adapter assuming all c748 entries have associatedrecord in a2 is wrong. Initial scope can explicitly qualify only c3de, with all other enlarged metadata initialized neutral.
4. This is not an exhaustive no-stale-descriptor proof. Under the explicit native contract that a queued descriptor still refers to the same live metadata allocation until its consumption, embedding the immutable capability in that allocation avoids losing identity merely through a pointer-only relay. A descriptor surviving free/reuse violates that contract; a magic tag or internal generation cannot detect an old pointer now addressing a new valid object. Keep this as a native lifetime precondition, not a proven universal quiescence result.
5. Unrelated late capture metadata writes do not invalidate image-associated H/L. Track actual image/population or captured-profile changes and lifetime, not every native write to27332bytes. Native S semantics remain untouched.

## Bounded implementation consequence

The proposed supported subset is feasible at the observed register/pointer seams, provided there is independently reviewed allocation qualification, explicit callsite capability handoff, full neutral initialization, revoke-before-free coverage for supported objects, and native live-pointer/queue lifetime contracts. No full object-size copy truncation was found in the reviewed pointer queue/envelopes; no assertion about all unreviewed paths. Missing qualification must permanently leave that descriptor/job neutral, never attach a later current profile or snapshot.
