# 早期代码承载候选与有限引用审查

2026-10-31。G6取得两个各32,640字节的早期装载候选，合计65,280字节。
这解决了“当前约44.8KB代码是否有足够早期容量”的数量问题；**尚未批准覆盖**。
全FF、局部解码和有限引用扫描不能单独证明没有其他所有者。

## 两个候选的边界

|候选解码/缓存地址，不含结束|实际早期复制别名|逻辑flash起点|内部容量|
|---|---|---|---:|
|60048040..6004ffc0|a0048040|406c8040|32,640|
|600c8040..600cffc0|a00c8040|40748040|32,640|

各自所在32KiB块从60048000/600c8000开始。前16字节为零，后32,752字节为FF。
候选保留16字节头、48字节FF前缀、64字节FF后缀。边界余量是设计选择，
并非原厂声明的保护范围；没有把这些头字段解释为“空闲标记”。

两处均被原厂600201f9的同一搬运覆盖：flash406b0000 → a0030000，657,408字节。
该调用返回后才到600201fe，晚于它的RTOS调用为60020392 → 6003009c。
本批重新核对这组实际参数及接续，不依赖“平坦解码文件等于全部已驻留”的假定。

容量65,280减当前未链接text44,793为20,487字节，尚须扣除installer、节对齐和链接
变化。两个不连续区也要求最终链接布局，不等同于一个连续65KiB缓冲区。
后续加入[冷清零和流水线安装组](PIPELINE_INSTALLATION_COHORT.md)后，text粗计45,733，
对应未扣installer/对齐的容量余量为19,547字节；本页区域资格状态不因此改变。

## 复用既有引用扫描，先审最有辨识力的候选

[脚本](../../tools/ep7_early_code_space.py)只复用PEN-F工具中的纯字面量/相对转移扫描
函数；不执行其固件读取、SHA、旧地址放置或模拟器入口。数据来自本地E-P7解码main。

|区域|缓存字面量|非缓存字面量|flash字面量|flash别名字面量|相对转移原始命中|
|---|---:|---:|---:|---:|---:|
|60048040..6004ffc0|331|1,919|27|150|22|
|600c8040..600cffc0|102|2,548|95|142|1|

这些计数是每字节对齐扫描的**原始匹配**，不能称作已确认引用。
23个相对转移的起始字节，都位于本批核对的另一条局部指令之内。例如：

- 60041e32来自读取6222cd9c的地址立即数。
- 600457bd/600457d5是MOV32的一部分，即已知原厂段结束地址选择器。
- 60052c7c/60053622是其他CALL的位移字节。
- 602fcbd3是实际CALL602c1291的位移内部；不是该局部解码下的独立CALLS。

这23处分类附带精确原指令，但不冒充完整CFG，尚未排除异常的中间字节入口。
已知6143ca00..6143e200 helper按47000800重定位后，同一原始转移扫描没有命中。

5,314个字面量匹配中，优先审查前方有FC字节的10项可能32位操作数。9项实际跨越
已核对的CALL、ADD立即数、CMP或分支边界；FC本身并非这些位置的32位操作码。
剩余60c34b61确实是MOV到D1的立即数406cc000，D0同时为0，经60c3eb6f保留/可选替换，
返回的两个word存入参数记录+68/+72。若按IEEE754 binary64解释，该值为230；
这只是数值解释，未证明记录的全部下游用途，仍保留未决项。
其他5,304个非优先字面量没有逐项分类，其他升级组件也未纳入本批。

## 冷初始化接续

600201fe是完整6字节 `mov (6218d984),d0`，下一条从60020204开始。它紧随早期
kernel复制返回，可作为后续bootstrap审查的候选接续；若采用，必须完整回放原操作
并保持原ABI、返回位置与实际启动寄存器。本次空间审查没有生成跳转、改动原指令或实现bootstrap。
后续[冷启动清零桥](COLD_START_CLEAR.md)已完成53字节独立候选及定向语义检查，
并补齐次核局部启动顺序；仍未批准本页两个代码区或安装该桥。

仍须证明其他CPU首次使用和CPU2池分配相对于该接续的顺序，处理私有RAM显式清零、
原厂池上界缩减的生效时机、代码可见性以及后续分段加载/覆盖。不能仅从本地CALL
先后推出全系统已停止或任何失败路径都安全。

[本次报告](../../research/ep7/early-code-space.json)含61条精确指令、区域形状、上述
有限扫描和分类。只运行这一新增静态探针，没有重跑host/目标对象测试或做SHA。
