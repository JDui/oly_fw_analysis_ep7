# EP7HSL 027 / 1.1v027 Rec HDR 试用版

**实机结果**　Rec 无响应，BODY 显示 `1.1D027`。使用原厂普通快门启用状态可在离线回放复现同一码。[028 修正版](EXPERIMENTAL_SD_028.md)

仅适用于 Olympus E-P7 原厂 1.1（build 1100）。026 在机身上可正常单拍，Rec 仍无响应。

原厂驱动表 `0x604cc98c` 与属性列表 `0x60430424` 给出机械、减震和静音单张的编号 0、12、30。三者都将有效属性 `1487` 设为 0。026 错把 `1487=1` 当作单张待机的准入条件，还把自定义自拍 24 当成静音单张。027 在 Rec 请求获准后暂时开启连拍属性，写入原厂 HDR1 的四帧配方，并在原厂触发清理路径撤销这组临时属性。快门选择沿用原厂单张驱动。

对照回放从原厂表读取三种单张的有效值，复现 026 的拒绝。027 在原厂待机判断通过后选中下一拍摄状态，并通过三种快门选择、HDR 帧数和临时设置清理检查。媒体就绪、消息传递及部分服务使用了夹具。实际曝光、合成、写卡和相机任务调度待实机确认。

## 刷入与回刷

1. 确认机型，备份照片及机身设置，使用充足电量的电池。刷前设为 **A 档、Natural（NAT）**。
2. 把 ZIP 中 `install/DCOLYMP` 复制到 SD 卡根目录，路径为 `SD:/DCOLYMP/E1429999.BIN`。
3. 关机插卡，按住 **OK** 开机。AF 指示灯开始亮起后松开 OK，等灯从常亮转为快速闪烁再关机。更新期间保持供电和插卡。
4. 取出更新卡后正常开机。尚未按过 Rec 时，BODY 显示 `1.1v027`。

回到原厂 1.1 时，换用 `restore-stock/DCOLYMP` 并按同一流程操作。每次卡上只放一套更新文件。回刷依赖机身更新入口。

## 实机验收

把 **按钮功能 → Rec（◎功能）** 设为 **HDR** 并退回取景。在 A 档选机械单张，依次试 **普通快门 → Rec → 普通快门**。预期前后各拍一张，Rec 保存一张 HDR1 合成照片。通过后切到 **静音单张（♥）** 重复一次。

如果 Rec 仍无响应，按一次后直接进固件版本页，记下 BODY 的完整文字。字母记录最近一次 Rec 的阶段，关机后清除。

| BODY 显示 | Rec 阶段 |
| --- | --- |
| `1.1v027` | 尚未识别到 Rec 的 HDR 按下事件 |
| `1.1K027` | 已识别按下，尚未构造拍摄事件 |
| `1.1Q027` | 已构造拍摄事件，尚未进入拍摄任务 |
| `1.1D027` | 拍摄任务收到事件，停在待机或拍摄许可检查 |
| `1.1C027` | 当前任务无法同步写入临时属性 |
| `1.1M027` | 模式、驱动或有效属性与单张 HDR 准入条件冲突 |
| `1.1P027` | 属性写入或 HDR 序列校验失败 |
| `1.1T027` | HDR1 已准备，开始调用原厂触发 |
| `1.1F027` | 原厂触发清理已恢复临时属性 |

成片以回放中能看到新照片为准。
