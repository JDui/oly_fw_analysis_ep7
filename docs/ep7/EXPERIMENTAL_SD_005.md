# EP7HSL 005 实验刷机包

适用目标：**Olympus E-P7，原厂固件 1.1 / build1100 / 型号1420**。
本包保留色轮编辑、四个 COLOR profile 的易失 H/L 和现有 CPU 照片处理路径。
H/L 重启归零；不包含持久化、所有拍摄模式适配或 RAW 元数据扩展。

这是按用户要求生成的 SD 实验刷机包，已经具备 E-P7 更新文件格式和安装文件名。
相机实测、物理启动入口及独立救砖能力尚未验证，可能出现无法正常启动等故障。
本机目前没有经过验证的完整备份/独立恢复手段；随包原厂文件不能保证救回所有故障。

## 文件选择

|文件|用途|
|---|---|
|`install/DCOLYMP/E1429999.BIN`|安装 EP7HSL 005，111,017,984 字节|
|`restore-stock/DCOLYMP/E1429999.BIN`|回到原厂 E-P7 1.1，111,017,984 字节|
|`manifest.json`|组件、构建来源、检查结果及实机验证边界|
|`evidence/`|最终原生验包、加载、色轮/冻结、worker 和 SD 路径隔离记录|

**每次只复制其中一个 DCOLYMP 文件夹到卡根目录。** 安装时不要复制整个压缩包目录，
不要混入原厂回刷文件；两个 BIN 名称相同，内容不同。不要用于 PEN-F、E-PL 或其他机型。

五组件0100/0101/0106/010e/0102和各自版本1100/0100/0100/0001/0100均保留，只有
main改变。后缀9999用于原生文件选择优先级，没有把组件版本改成9999。版本显示仍可能
为1.1，应通过新增H/L界面与实际行为确认安装，而不是仅看版本号。

## 实验 SD 安装路线

`DCOLYMP/E1429999.BIN` 来自 E-P7 原生文件选择代码和已通过的软件路径检查。
以下 **OK+开机、AF灯指示** 参考 fishcu 在 PEN-F 上公开实测的
[SD 安装说明](https://github.com/fishcu/oly_fw_analysis/blob/alpha-20261017/releases/alpha-20261017/INSTALLATION.md)，
用于 E-P7 的实验路线尚未现场确认；本包不把这一步写成 E-P7 官方操作或已验证事实。

1. 在相机仍正常工作时记录重要设置和当前版本；先用普通 P/A 与 Natural 模式拍一张
   基线照片。准备可靠SD卡并先备份卡上照片。电池充满，断开USB，相机关机。
2. 解压文件，在电脑上把 **install 下的 DCOLYMP** 复制到卡根目录。检查最终路径是
   `<卡根目录>/DCOLYMP/E1429999.BIN`，并确认文件长度111,017,984字节；DCOLYMP中
   只保留本次选择的更新文件，避免旧文件参与原生优先级选择。
3. 相机关机时插卡，按住 **OK** 再开机。参考方案在更新指示开始后松开OK：屏幕保持
   黑色，AF辅助灯在写入时常亮，完成后快速闪烁。E-P7是否完全相同仍属本次现场观察。
4. 写入指示期间保持供电，不拔卡或取电池。只有确认实际完成指示后才关机；未知指示
   没有已经验证的安全强制中止时长，不要按“固定几分钟”推定完成。
5. 完成后取出更新卡，在电脑上移走其更新文件；使用没有更新文件的卡正常开机，
   不按OK。若只是正常进入拍摄画面，不能据此认定固件已安装。

此流程需要用户现场操作。本工具没有自动复制到任何实际SD卡，也没有连接或刷写相机。

## 首次功能检查

先确认普通菜单、Natural拍摄、回放和存储可用，再进入COLOR的原有编辑界面。
通过原厂类别切换控件寻找新增H/L类别；其导航沿用E-P7，**不套用PEN-F的Delete切轴**。
H/L文本应能显示类似`H 01 +0`、`L 03 -4`的当前扇区与值。

依次检查四个COLOR profile：小幅修改单个颜色的H，再单独修改L，切换扇区与类别，
退出再进入；观察profile之间的值是否独立。固定曝光、白平衡和场景拍零值/H变化/
L变化照片，确认JPEG可以回放且变化与选择一致。H/L是易失值，正常重启后应归零。
异常时记录页面、操作顺序、profile和样片；没有经过验收的模式不承诺H/L生效。

## 原厂回刷的适用范围

需要回原厂时，选择 **restore-stock 下的 DCOLYMP**，按同一 SD 路线使用。
该文件与原厂五组件输入逐字节一致，没有H/L改动；不应把回刷理解为恢复出厂设置。
它要求相机的更新路径仍能运行。若启动或更新入口已经损坏，不能保证它可用；它不是
设备唯一参数/校准备份、启动ROM镜像或独立救砖程序。

## 本包的核对范围

106个已有目标对象重新链接；98项补丁、原厂启动前缀、32槽CPU2池和8KiB镜像初始化
状态均核对。最终容器与通过原生更新器完整解码/校验的输入逐字节一致；五项写入请求
在模拟边界截获，错误停止行为检查通过。既有GUI/worker验证通过字节一致性复用。

封装复用fishcu的parse → replace_payload → reconstruct。保留原生加和校验、文件
回读和ZIP的CRC/内容检查，没有SHA校验。原生验包及离线H/L检查不是相机启动、真实
显示/照片质量、物理flash写入或独立恢复的验收。
